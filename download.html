Open and inspectable

Thendrask is MIT-licensed and built from its public GitHub repository. Microsoft passwords are never provided to the launcher. Refresh tokens are encrypted using Windows-provided secure storage.

Who publishes it?

Thendrask is maintained and released by Sxarlos from the public project repository.

Does it contain Minecraft?

No. The launcher downloads the official game files after you sign in with an account that owns Minecraft: Java Edition.

How are updates verified?

Updates are retrieved from the official GitHub Releases feed. For the installer, compare the published SHA-256 checksum before running it.

Where are tokens stored?

Only the Microsoft refresh token is retained, encrypted locally with Windows secure storage. Your Microsoft password is never seen or stored.

Why does Windows warn me?

The current installer is unsigned, so SmartScreen may identify it as coming from an unknown publisher. This warning does not verify whether a file is safe.

Something looks suspicious?

Do not run the file. Re-download it from the official release, check its hash, and report the release through the project’s security channel.

Windows 10 or 11, 64-bit

4 GB minimum; 8 GB or more recommended for modpacks
Java
No separate Java installation required

For initial setup, authentication and downloads
Minecraft account
Microsoft account that owns Minecraft: Java Edition

Java is handled automatically

Thendrask determines the Java version required by each Minecraft release and downloads a compatible runtime when necessary. You can still select a custom Java installation in Settings.

Advanced Java configuration

Experienced users can select a custom Java executable in Settings. Per-instance paths remain available when a pack needs a specific runtime or JVM configuration.

Installation steps

STEP 01

Download the installer

Download the latest .exe only from the official GitHub release. Before running it, compare the file’s SHA-256 hash with the checksum published alongside that release.

STEP 02

Run the installer

Double-click the downloaded file and follow the prompts. Choose your install location - a standard Windows installer. Thendrask Launcher will launch automatically when done.

STEP 03

Sign in with Microsoft

Log in with your Microsoft account. Your password is entered on Microsoft's own page - Thendrask Launcher never sees it. Only an encrypted token is stored locally.

STEP 04

Browse, install, play

Open the modpack browser, pick a source (Modrinth, CurseForge, FTB, ATLauncher, or Technic), install a pack, and hit Play. First launch downloads the game version and assets automatically.

About the Windows warning

The current installer is not yet code-signed, so Windows SmartScreen may show “Unknown publisher.” Verify that the file came from the official GitHub release and compare its SHA-256 checksum before running it. Open source code helps inspection, but it does not by itself prove that a particular downloaded binary is safe.
